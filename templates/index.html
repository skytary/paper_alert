    ⚙ Settings

    Summary language
    Language for the summary, data, and key findings of newly fetched papers. Papers already in the library keep their language.
    Start date
    Fetch only alert emails received on or after this date. Older unread emails are left untouched in Gmail; clear the date to include them again.
    Emails per fetch
    How many emails one click of Fetch processes. Each email costs about $0.04.
    Fetch order
    Which waiting emails to process first.
    Zotero
    Show the "➜ Zotero" button on each paper. Turn off to hide all Zotero features.
    Auto-send to Zotero
    During Fetch, send new papers with at least this score to Zotero automatically.
    If already in Zotero
    A paper counts as already in Zotero when its DOI or title matches an item in your library. Either way no duplicate is created. "Fill in" adds only details that are empty in Zotero (DOI, abstract, volume, pages...); tags, notes, and attachments are never changed.
    Where to send
    Which Zotero collection a newly added paper goes into. Papers already in Zotero stay where they are.
    Collection
    Every paper goes into this collection.
    Collection for each category
    A paper with several categories goes into each matching collection.
    Criteria file
    Claude reads this file and picks the collections whose criteria fit the paper (about one cent per paper).
    If nothing fits
    Where a paper goes when no category or criterion matches.
